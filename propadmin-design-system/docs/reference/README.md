# Original design documents

These files come from the original platform repository, with product naming adapted for Propadmin. `DESIGN-SYSTEM.md` is the current specification. `DESIGN-GUIDE.md` is historical and its conflicting visual rules are superseded.

Paths beginning `frontend/` and references to graph, tenant settings, application providers or old mockup plans describe the source application. They are not extra dependencies of this kit. Use the portable `../STYLE-GUIDE.md`, `../COMPONENT-SYSTEM.md` and `../INTEGRATION.md` for a new project.
